## 15:40 WIB — Filter periode Juni "cuma sedikit item" — root cause + fix (frontend, BELUM deploy)

**Keluhan:** Filter periode 01 Jun–31 Jul 2026 cuma menampilkan 3 company (AADC/LCP/PPGL, semua GL ALLOY, 675 MT), sementara kartu KPI atas semua baca **0**. User: "harusnya Juni sudah banyak item."

**Investigasi (data live via `/api/data` Sheets):** dari 40 company, hanya 8 yang punya tanggal cycle di Jun–Jul 2026. 3 tampil, 5 tersembunyi karena **dua sebab yang bertumpuk**:

1. **Bug parser tanggal** — `pDate()` (02-period-filter.js) hanya mengenali `DD/MM/YYYY` & `YYYY-MM-DD`. Banyak tanggal di Sheet ditulis `30-Jun-26`, `29-Jun-26`, `15-Jun-26`, `12 Mei 2026`, `29 Apr 2026` → parse ke `null` → ke-skip diam-diam.
2. **Tipe "Revision Request" tidak dibaca** — `cycleDates()`/`companyInPeriod()` cuma ambil tanggal dari cycle `Submit #N` / `Revision #N` / `Obtained #N`. 5 company Juni (GNG, HDP, KAN, MJU, SMS) tanggal Juni-nya HANYA ada di cycle "Revision Request — <produk>", jadi tak pernah cocok periode. (Verifikasi: parser fix SAJA menambah 0 company karena semua cycle Submit/Obtained sudah pakai `DD/MM/YYYY`; yang format aneh cuma di baris Revision Request.)
3. **KPI 0 vs breakdown 675** — `buildAvqPageKPIs` (19-init.js) pakai `canonicalObtainedFiltered` (gate lewat **PERTEK terbit** = releaseDate Submit berpasangan) → 0 untuk Juni; breakdown `buildAvailableQuota` pakai `canonicalObtained` (all-time/ledger) → 675. Kontradiksi di satu halaman.

**Ubah:**
- `pDate()` (02-period-filter.js): tambah cabang parse `DD-Mon-YY` / `DD Month YYYY` (EN+ID) via `_MONTH_NAME_MAP`. Superset murni — cuma menyelamatkan string yang tadinya `null`; nomor PERTEK (`1106/ILMATE/...`) tetap `null`.
- `companyInPeriod()` (02-period-filter.js): untuk cycle `Revision Request …` ikut cek `pDate(submitDate)/pDate(releaseDate)`. **Row-inclusion saja** — math kuota (canonicalObtained dll.) tetap skip via aturan `_fromRevReq`/"Revision Request", jadi tidak ada MT dobel.
- `buildAvqPageKPIs()` (19-init.js): basis obtained diganti `canonicalObtainedFiltered` → `canonicalObtained` agar KPI card = breakdown di bawahnya. **Sengaja beda** dari Overview KPI2 (yang tetap "quota terbit di periode" = 0 utk Juni); halaman AVQ menjawab "saldo company yang aktif di periode".
